# DONE — Visión y alcance del proyecto

**Versión:** 1.0  
**Estado:** Documento inicial  
**Equipo:** 2 desarrolladores

## 1. Descripción del proyecto

DONE es una aplicación web con inteligencia artificial diseñada para ayudar a las personas a organizar y resolver sus gestiones cotidianas.

Su principal objetivo es ir más allá de las aplicaciones tradicionales de gestión de tareas, permitiendo que la IA no solo recomiende acciones, sino que también pueda ejecutarlas con la autorización del usuario.

## 2. Público objetivo

DONE está dirigido a cualquier persona que necesite organizar, gestionar o resolver tareas pendientes de su vida cotidiana.

## 3. Plataforma

La primera versión será una aplicación web responsive, accesible desde ordenadores y dispositivos móviles.

## 4. Funcionalidades previstas

- Gestión de tareas pendientes y completadas.
- Chat con inteligencia artificial.
- Calendario propio y sincronización con calendarios externos.
- Lectura, resumen y gestión de correos electrónicos autorizados.
- Detección y cancelación de suscripciones.
- Búsqueda, comparación y realización de reservas.
- Organización de planes y reuniones.
- Notificaciones configurables por el usuario.
- Historial de operaciones realizadas por la IA.

## 5. Seguridad y privacidad

- Registro mediante correo y contraseña o Google.
- Confirmación del usuario antes de ejecutar acciones.
- Acceso a servicios externos mediante permisos autorizados.
- Protección de datos personales.
- Posibilidad de solicitar la eliminación de la cuenta, con un periodo de recuperación de 30 días sujeto a las obligaciones legales aplicables.
- Copias de seguridad automáticas diarias.
- Registro de errores y operaciones realizadas.

## 6. Organización del desarrollo

El proyecto será desarrollado inicialmente por dos personas.

Se utilizará GitHub para gestionar el código, la documentación y las tareas mediante GitHub Projects.

El trabajo se dividirá en funcionalidades independientes, utilizando ramas y pull requests para revisar los cambios.

Cada funcionalidad deberá superar pruebas manuales y automáticas antes de integrarse en la rama principal.

## 7. Infraestructura y tecnología

La selección definitiva de las tecnologías, los servicios de inteligencia artificial y el alojamiento se realizará tras comparar las alternativas disponibles.

Se priorizarán soluciones gratuitas que permitan desarrollar rápidamente y ampliar la aplicación en el futuro.

Existirán dos entornos diferenciados: desarrollo y producción.

## 8. Modelo de negocio

DONE tendrá un modelo de suscripción mensual. El precio se determinará posteriormente, considerando los costes de infraestructura, inteligencia artificial y mantenimiento.

## 9. Alcance inicial

La primera versión buscará integrar organización de tareas, asistencia mediante IA y automatización de gestiones seleccionadas.

Las funcionalidades se desarrollarán progresivamente, comprobando su funcionamiento antes de incorporar nuevas capacidades.

El sistema se probará inicialmente entre los dos desarrolladores, antes de abrir el acceso a usuarios externos.

## 10. Objetivo a largo plazo

Convertir DONE en un asistente personal de inteligencia artificial capaz de coordinar y ejecutar diferentes gestiones cotidianas de forma segura, eficiente y supervisada por el usuario.
